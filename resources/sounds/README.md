# Sounds that come with Sun Loops Studio

These files are built into the program (they are not read from disk at run time) and are used **unchanged**.

* `cyber-hub/` - the **Cyber-Hub** sound theme by Hubert (https://github.com/Hubert9204/Cyber-Hub), 30 stereo Ogg Vorbis
  system sounds. The theme's own `index.theme` is kept next to them: *Creative Commons Attribution-NoDerivatives 4.0
  International (CC BY-ND 4.0), Copyright (C) 2026 by Hubert. Commercial use is permitted. No modifications, forks or
  rebranding of the distributed material are allowed.* They are played back as they are; the program never rewrites them.
* `intro.wav` - the start-up sound by Hubert (5 s, 48 kHz, 24 bit stereo), played when the program opens.
